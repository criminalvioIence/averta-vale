Averta Vale Order Alerts — private local demo PWA
Upload all files to the root of a GitHub repository and enable GitHub Pages from main /(root). Open the published URL in iPhone Safari, Share > Add to Home Screen.
Notifications are local demo notifications while the app is running. This does not connect to Shopify, create orders, or charge payments. For iOS notifications, install the Home Screen web app and grant permission from the button. Background/remote push requires a push backend and is not included.

Update: custom logo and MP3 are included. Alert interval can be selected from 2–60 seconds. MP3 playback is only attempted while the page is visible and browser audio permission/autoplay rules allow it. iOS system notification sounds cannot be customized by a web app. Keep the app clearly labeled as a demo; no Shopify API is connected.
